1. Ringkasan Eksekutif

Pengembangan ini mencakup penambahan dua fitur strategis pada portal resmi JDIH Kementerian Koordinator Bidang Pangan (jdih.kemenkopangan.go.id), yaitu:

  1. Statistik Produk Hukum Berdasarkan Jenis Peraturan & Tahun: Menyajikan data agregasi regulasi secara transparan, akurat, dan interaktif dengan kalkulasi 100% data riil database (Zero Dummy Data), kartu KPI eksekutif, filter ganda tersinkronisasi AJAX, visualisasi Chart.js, serta fitur ekspor PNG.
  2. Sistem Klasifikasi Konten Video (Galeri & Aksesibilitas): Memperluas pengelolaan video dengan dukungan relasi Many-to-Many (1 video dapat terhubung ke banyak kategori tanpa duplikasi), normalisasi URL YouTube otomatis, form admin dinamis, serta menghadirkan halaman publik khusus Aksesibilitas (/aksesibilitas) ramah disabilitas dan integrasi pada Galeri (/galeri).

Prinsip Arsitektur: Seluruh implementasi dilakukan secara additive dan backward-compatible. Tidak ada penghapusan fitur existing, tidak ada penulisan ulang modul yang telah stabil, dan struktur database dimigrasikan secara aman tanpa gangguan terhadap konten yang sudah beroperasi.

2. Fitur 1: Statistik Produk Hukum

Modul statistik produk hukum dapat diakses oleh publik pada alamat /statistik-produk-hukum dan terintegrasi langsung pada menu navigasi portal.

A. Aturan Agregasi & Integritas Data

  • Kategori Peraturan Murni: Hanya menyertakan dokumen yang bertipe peraturan (master_document_id = 1) dan berstatus aktif (is_active = 1). Dokumen rancangan PUU, artikel, monografi, atau draft unpublished dikecualikan.
  • Basis Tahun Riil: Menghitung berdasarkan tahun penetapan dokumen (kolom year), bukan waktu pengunggahan ke CMS (created_at).
  • Persentase Dinamis: Dihitung secara real-time terhadap total dokumen dalam filter yang sedang dipilih:
    Persentase (%) = (Jumlah Dokumen per Jenis / Total Dokumen Terfilter) * 100%

B. Komponen Antarmuka & Interaktivitas

  • Ringkasan Eksekutif (4 Kartu KPI): Total Produk Hukum, Total Jenis Peraturan Aktif, Tahun Terbanyak, dan Rasio Status (Berlaku vs Tidak Berlaku).
  • Dual Filter Terintegrasi: Pilihan Tahun (2015 s.d. 2026) dan Jenis Peraturan dengan tombol Reset. Perubahan filter otomatis memicu pembaruan via AJAX tanpa memuat ulang halaman (*zero page flicker*).
  • Sinkronisasi URL Browser: Parameter filter tersinkronisasi ke URL melalui window.history.pushState sehingga tautan statistik dapat langsung dibagikan atau disimpan (bookmarkable).
  • Ekspor Dokumen ke Gambar (PNG): Tersedia tombol unduh beresolusi tinggi untuk Tabel Data dan Grafik menggunakan html2canvas.
  • Visualisasi Ganda (Chart.js):
    1. Grafik Batang Horisontal/Vertikal: Distribusi per Jenis Peraturan dengan warna master.
    2. Grafik Tren Tahunan: Sebaran dokumen per tahun dengan breakdown status keberlakuan (Berlaku vs Tidak Berlaku).

3. Fitur 2: Klasifikasi Video Galeri & Aksesibilitas

Fitur ini memungkinkan pengelompokan konten video multi-tujuan guna memenuhi standar portal keterbukaan informasi dan ramah disabilitas.

A. Skema Multi-Klasifikasi (Many-to-Many)

Satu rekaman video dapat memiliki lebih dari satu kategori klasifikasi secara simultan. Sebagai contoh:

  • Video ID 1 ("Sharing Session Penguatan Layanan Advokasi Hukum"): Diberi tanda centang pada Galeri dan Aksesibilitas. Video ini secara otomatis muncul di halaman Galeri (/galeri) sekaligus di halaman Aksesibilitas (/aksesibilitas) tanpa terjadi duplikasi baris pada tabel utama galleries.
  • Video ID 2: Hanya diklasifikasikan sebagai Galeri, sehingga hanya tampil di /galeri dan tidak tampil di /aksesibilitas.

B. Halaman Publik Aksesibilitas (/aksesibilitas)

  • Khusus Video: Menyajikan hanya konten video panduan dan ramah aksesibilitas. Foto atau galeri gambar umum otomatis tersaring keluar.
  • Kartu Video Modern: Dilengkapi thumbnail 16:9, label badge hijau "Aksesibilitas", tanggal publikasi, judul, potongan deskripsi ramah pembaca layar, dan ikon putar interaktif.
  • Modal Player Responsif: Membuka popup video resmi YouTube (#popup-video) dengan rasio layar optimal dan pemutaran otomatis.
  • Pencarian & Pengurutan: Form pencarian instan dan dropdown pengurutan (Terbaru / Terlama).
  • Empty State Informatif: Tampilan ramah dan ilustratif apabila belum ada video yang sesuai dengan kata kunci pencarian.

C. Manajemen Konten di Admin Panel

Pada CMS Admin (Informasi → Gallery):

  • Listing: Menampilkan label kategori warna pada kolom Klasifikasi (Hijau untuk Aksesibilitas, Biru untuk Galeri, Abu-abu untuk Foto). Tersedia filter dropdown klasifikasi.
  • Form Dinamis: Form otomatis menyembunyikan field URL Video dan Checkbox Klasifikasi jika tipe konten yang dipilih adalah Foto, dan menampilkannya jika memilih Video.
  • Normalisasi Link YouTube: Input URL YouTube dalam bentuk watch?v=..., youtu.be/..., atau shorts/... otomatis dikonversi menjadi format embed resmi (https://www.youtube.com/embed/...) sebelum disimpan ke basis data.

4. Database & Migrasi

Migrasi dijalankan melalui file database/migrations/2026_10_26_000001_create_video_classifications_and_pivot_tables.php.

A. DDL Tabel Baru

-- Tabel Master Klasifikasi Video
CREATE TABLE `video_classifications` (
  `id` bigint(20) unsigned NOT NULL AUTO_INCREMENT,
  `code` varchar(50) NOT NULL UNIQUE,
  `name` varchar(100) NOT NULL,
  `description` text DEFAULT NULL,
  `sort_id` int(11) NOT NULL DEFAULT 0,
  `is_active` tinyint(1) NOT NULL DEFAULT 1,
  `created_at` timestamp NULL DEFAULT NULL,
  `updated_at` timestamp NULL DEFAULT NULL,
  PRIMARY KEY (`id`)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_unicode_ci;

-- Tabel Pivot Relasi Many-to-Many
CREATE TABLE `gallery_video_classifications` (
  `id` bigint(20) unsigned NOT NULL AUTO_INCREMENT,
  `gallery_id` bigint(20) unsigned NOT NULL,
  `classification_id` bigint(20) unsigned NOT NULL,
  `created_at` timestamp NULL DEFAULT NULL,
  `updated_at` timestamp NULL DEFAULT NULL,
  PRIMARY KEY (`id`),
  UNIQUE KEY `gallery_video_class_unique` (`gallery_id`, `classification_id`),
  CONSTRAINT `gvc_gallery_fk` FOREIGN KEY (`gallery_id`) REFERENCES `galleries` (`id`) ON DELETE CASCADE,
  CONSTRAINT `gvc_classification_fk` FOREIGN KEY (`classification_id`) REFERENCES `video_classifications` (`id`) ON DELETE CASCADE
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_unicode_ci;

B. Perubahan Kolom Tabel Existing

-- Penambahan urutan tampil pada tabel galleries
ALTER TABLE `galleries` ADD `sort_id` INT NOT NULL DEFAULT 0 AFTER `thumbnail`;

-- Penambahan deskripsi multibahasa pada tabel galleries_lang
ALTER TABLE `galleries_lang` ADD `description` TEXT NULL AFTER `title`;

5. Referensi API Publik

Seluruh endpoint API mengembalikan data dalam format standar JSON dengan header Content-Type: application/json.

Endpoint Method Parameter Query Deskripsi & Kegunaan
/api/statistics/legal-products GET year (int), rule_type_id (int) Mengambil payload lengkap: ringkasan KPI, distribusi jenis peraturan, tren tahunan, dan opsi filter aktif.
/api/statistics/legal-products/by-type GET year (int) Mengambil data statistik khusus distribusi jenis peraturan beserta persentase dan warna grafik.
/api/statistics/legal-products/by-year GET rule_type_id (int) Mengambil data statistik tren tahunan dengan rincian status keberlakuan dokumen.
/api/videos GET category (string: gallery | accessibility), search, sort Mengambil daftar video terpublikasi dengan filter kategori klasifikasi, pencarian, dan paginasi.
